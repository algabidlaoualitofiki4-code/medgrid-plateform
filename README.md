# MedGrid Platform

Plateforme distribuée de gestion du parcours patient et de supervision clinique en temps réel (REST, gRPC, SOAP, RabbitMQ).

## Règles de travail de l'équipe
- **Contrats d'abord** : les contrats dans `/contracts` sont la référence partagée. Consultez `contracts/VERSIONING_GUIDE.md` avant toute modification.
- **Branches & PR** : travaillez sur des branches `feat/...` ou `contract/...` et faites relire chaque Pull Request par un autre membre avant fusion sur `main`.
- **Sécurité** : aucun secret, mot de passe ou clé privée ne doit être commité dans le dépôt.
